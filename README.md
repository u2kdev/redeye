# Red Eye 👁️🔴

Система компьютерного зрения на базе **YOLO** и **OpenCV** для обнаружения людей в красной одежде в реальном времени с веб-камеры или видеофайла.

---

## 🎯 Возможности

- **Точное обнаружение людей**: Использование нейросетей YOLO (`yolov8` / `yolo11`) с фильтрацией класса `person`.
- **Интеллектуальный анализ цвета одежды**: Извлечение области торса (исключая голову и нижнюю часть ног) для точного анализа оттенка ткани.
- **Двухдиапазонный HSV-фильтр**: Полноценный охват красного спектра (0–10° и 160–180° Hue) с устранением фоновых шумов и теней.
- **Интерактивное управление на лету**:
  - `Q` / `ESC` — Выход
  - `R` — Переключение режима: показывать только людей в красном или всех людей
  - `T` — Отображение зоны торса, используемой для цветового анализа
  - `+` / `-` — Регулировка порога чувствительности к красному цвету
- **Отображение FPS и статистики** в реальном времени.
- **Поддержка записи видео** (`--save output.mp4`).

## 🚀 Установка

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/u2kdev/redeye.git
   cd redeye
   ```

2. **Создайте и активируйте виртуальное окружение (рекомендуется)**:
   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # Linux / macOS:
   source venv/bin/activate
   ```

3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

## 💻 Использование

### Стандартный запуск с веб-камеры:
```bash
python main.py
```

### Запуск с дополнительными параметрами:
- Использовать другую камеру (индекс 1):
  ```bash
  python main.py --camera 1
  ```

- Задать более строгий или мягкий порог красного (по умолчанию `0.12`, т.е. 12%):
  ```bash
  python main.py --red-threshold 0.18
  ```

- Показывать только людей в красном (скрывать остальных):
  ```bash
  python main.py --show-only-red
  ```

- Использовать более тяжелую/точную модель (например `yolov8s.pt` или `yolo11n.pt`):
  ```bash
  python main.py --model yolo11n.pt
  ```

- Сохранять результат в видеофайл:
  ```bash
  python main.py --save recorded.mp4
  ```

## ⚙️ Как это работает

1. **Детекция объекта**: Кадр с камеры передается в модель YOLO, которая находит координаты людей (`class 0: person`).
2. **Локализация одежды**: Из каждого bounding box вырезается область туловища (от 15% до 70% по высоте и с небольшим отступом по бокам), чтобы отсечь фон, лицо и обувь.
3. **Цветовая сегментация (HSV)**: Вырезанный фрагмент переводится в цветовое пространство HSV, где отслеживается диапазон красного цвета (включая темные и насыщенные оттенки).
4. **Морфологическая обработка**: Применяется `cv2.morphologyEx` для удаления одиночных шумовых пикселей.
5. **Классификация**: Вычисляется соотношение площади красных пикселей к площади области. Если порог превышен — объект помечается красной рамкой со статусом **"RED CLOTHES"**.
